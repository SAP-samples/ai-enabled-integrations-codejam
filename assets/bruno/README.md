# Bruno collections

This folder contains [Bruno](https://www.usebruno.com/) REST client collections for testing the APIs used in this CodeJam.

## Collections

- **Service Centre Locator** - requests for testing the Service Centre Locator API directly
- **Customer Service system** - requests for testing the customer service system API directly

## How to use

1. Open Bruno and click **Open Collection**
2. Navigate to this folder and open the collection you want to use
3. Update the environment variables with the URLs and credentials provided by your instructor 🔐
